# 🧙‍♂️ Desafio Classificador de Nível de Herói

Este repositório contém a solução do **Desafio Classificador de Nível de Herói**, cujo objetivo é praticar conceitos fundamentais de **lógica de programação** utilizando JavaScript.

---

## 📌 Objetivo do Desafio

Criar um programa que:

- Armazene o **nome** e a **quantidade de experiência (XP)** de um herói
- Utilize **estruturas de decisão** para classificar o nível do herói
- Utilize **laços de repetição** para classificar mais de um herói
- Exiba no console a mensagem final com o nome e o nível do herói

---

## 🛠️ Conceitos Utilizados

- Variáveis
- Operadores relacionais e lógicos
- Estruturas de decisão (`if / else if / else`)
- Laços de repetição (`for` e `while`)
- Template Strings

---

## 🧠 Regras de Classificação

| XP do Herói             | Nível      |
| ----------------------- | ---------- |
| Menor que 1.000         | Ferro      |
| 1.001 a 2.000           | Bronze     |
| 2.001 a 5.000           | Prata      |
| 5.001 a 7.000           | Ouro       |
| 7.001 a 8.000           | Platina    |
| 8.001 a 9.000           | Ascendente |
| 9.001 a 10.000          | Imortal    |
| Maior ou igual a 10.001 | Radiante   |
